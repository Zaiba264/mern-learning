# Laundry Wallah / Laundry Mart

## Project Description
This project is a simple laundry service webpage created using HTML. It provides information about laundry services, pricing, and booking.

## Features
- Welcome heading and About section
- Laundry image
- List of laundry services
- Price list displayed in a table
- Booking form with Name, Email, and Phone fields
- Contact information in the footer

## Technologies Used
- HTML5

## How to Run
1. Open the project folder.
2. Open `index.html` in a web browser.
3. Explore the services, prices, and booking form.
