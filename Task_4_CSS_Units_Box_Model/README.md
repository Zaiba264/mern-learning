# Task 4: CSS Units, Box Model and Fonts

## Description
This project demonstrates CSS viewport units, the CSS box model, font styling, and gradient backgrounds using HTML and CSS.

## Technologies Used
- HTML5
- CSS3

## Features
- Viewport-based spacing using `vw` and `vh`
- CSS box sizing with `border-box`
- Image styling with fixed dimensions and rounded corners
- Button styling with padding, font weight, and rounded corners
- Linear gradient background on the button
- Font family and font size styling

## Project Files
- `index.html` — HTML structure
- `style.css` — CSS styling
- `boxmodel.webp` — Box model illustration

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.

## Learning Outcome
Practised CSS units, margins, padding, borders, box sizing, fonts, and linear gradients.
