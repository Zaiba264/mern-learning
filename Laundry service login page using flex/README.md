# Task 6 – CSS Login Page Using Flexbox

## Project Overview
This project is a responsive login page for a Laundry Mart application, created using HTML and CSS. It demonstrates the use of CSS Flexbox to arrange an image section and a login form side by side.

## Features
- Split-screen login page layout.
- Left section displays an illustrative image.
- Right section contains a login form.
- Email and password input fields.
- Forgot Password link.
- Login button with rounded corners and hover effect.
- Register Now link for new users.
- Clean and user-friendly interface.

## Technologies Used
- HTML5
- CSS3
- CSS Flexbox

## How to Run the Project
1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. Use Live Server to preview the login page.
