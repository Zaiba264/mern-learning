# Laundry Services – Hero Section

## Project Description
This project is a responsive Laundry Services landing page created using HTML and CSS. It features a clean and attractive design that introduces laundry services and encourages users to book a service.

## Features
- Navigation bar with Home, Services, About Us, and Contact Us links.
- Attractive hero section with a heading and description.
- Laundry-related image.
- Book a Service Today button.
- CSS styling using colors, margins, padding, and borders.
- Layout created using CSS display and positioning properties.
- Viewport units (`vw` and `vh`) for sizing.

## Technologies Used
- HTML5
- CSS3

## Concepts Practised
- CSS Display Properties
- CSS Positioning
- Viewport Units
- Box Model
- Image Styling
- Navigation Bar Styling

## Project Structure
- `index.html` – Website structure.
- `style.css` – Website styling.
- `README.md` – Project documentation.git add
