# Task 7 – Responsive Laundry Services Hero Section

## Project Overview
This project enhances the existing Laundry Services Hero Section by implementing responsive web design using HTML and CSS. The webpage adapts to desktop, tablet, and mobile screen sizes using CSS Media Queries and CSS Variables.

## Features
- Responsive navigation bar.
- Desktop, tablet, and mobile layouts.
- Navigation links hidden on mobile screens.
- Responsive hero section with text and image.
- Flexbox layout for arranging content.
- Optimized font sizes and spacing for different screen sizes.
- CSS Variables for reusable styling.
- Clean and user-friendly interface.

## Technologies Used
- HTML5
- CSS3

## CSS Concepts Practiced
- CSS Variables
- Media Queries
- Flexbox
- Display Properties
- Flex Direction
- Positioning
- Width and Height
- Responsive Images
- Margin and Padding

## Responsive Breakpoints
- Desktop: Above 1024px
- Tablet: 601px to 1024px
- Mobile: Up to 600px

## How to Run
1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser.
4. Resize the browser or use Developer Tools to test responsiveness.
