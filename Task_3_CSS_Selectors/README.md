# Assignment 3: CSS Selectors

## Description
This project demonstrates the use of CSS selectors to style an HTML webpage.

## Concepts Covered
- Element selectors
- Class selectors
- ID selectors
- Text color and background color
- Font size and text styling
- Styling paragraphs and headings
- Styling links using CSS selectors
- Ordered and unordered lists

## Technologies Used
- HTML5
- CSS3

## Project Files
- `index.html` — Contains the webpage structure.
- `style.css` — Contains the styling rules.
  
## How to Run
1. Open `index.html` in a web browser.
2. Make sure `style.css` is linked correctly to the HTML file.
